AC SERVICE POINT WEBSITE — IMAGES KE BAARE MEIN ZAROORI JAANKARI
==================================================================

Aapki original website (zip file) mein images ke liye khud ki koi
JPG file nahi thi — saari images seedhe Pexels.com ke online server
se load ho rahi thi (link ke through), zip ke andar koi image file
maujood nahi thi.

Is naye HTML/CSS version mein maine "images" folder ke andar strictly
JPG format ki placeholder images bana di hain, taaki:
  1) Website turant offline / Notepad++ se chalayi ja sake
  2) Design, layout aur sections bilkul original jaise hi dikhein
  3) Har filename ka matlab clear ho (kaunsi image kis section ke liye hai)

Agar aap EXACT wahi original stock photos chahte hain jo pehle
website par thi, to neeche di gayi list mein har local filename ke
saamne uska original Pexels source link diya gaya hai. Bas us link
ko browser mein khole, photo par right-click karke "Save Image As"
karein, aur usi filename se "images" folder ke andar save kar dein
(purani placeholder file replace ho jayegi). Ye sabhi photos Pexels
par free-to-use license ke saath available hain.

NOTE: Kyunki maine ye images seedhe download nahi ki (mera tool
seedhe Pexels server se image files download nahi kar sakta), maine
har jagah sahi size/aspect ratio ki labeled placeholder JPG banayi
hain jisse layout turant sahi dikhta hai. Aap chahein to inhe as-it-hai
rakh sakte hain, ya upar diye gaye links se asli photos download
karke replace kar sakte hain — filename same rakhna zaroori hai,
baaki kuch badalne ki zaroorat nahi hai.
